# AIroad Tractor Dispatcher

Полноценный веб-инструмент для диспетчеризации уборочной техники: разбивает город по GEO.kml, позволяет назначать клетки и дороги тракторам, строит маршруты с визуализацией в реальном времени и выгружает результат в `routes_grid.kml`.

## Структура проекта

```
project/
  server.py                 # Flask + Socket.IO сервер
  route_builder_grid_v7_1.py# CLI-скрипт маршрутизации
  route_builder/            # модульная логика построения
  static/                   # фронтенд (Leaflet + Socket.IO)
  templates/                # map.html
  data/                     # входные/выходные файлы (GEO, RoadCity, kml)
  cache/                    # кэш геокодера
  requirements.txt
  env.example
  app_settings.json
```

## Быстрый старт

1. Установите зависимости:
   ```bash
   cd project
   python -m venv .venv && source .venv/bin/activate  # опционально
   pip install -r requirements.txt
   ```
2. Скопируйте пример окружения и пропишите ключи:
   ```bash
   cp env.example .env
   # заполните GOOGLE_MAPS_API_KEY и YANDEX_GEOCODER_API_KEY (опционально)
   ```
3. Подготовьте входные данные в каталоге `project/data/`:
   - `GEO.kml` — границы города (полигон/мультиполигон);
   - `RoadCity.kml` — все дорожные сегменты.
4. Запустите сервер:
   ```bash
   python server.py
   ```
5. Откройте http://127.0.0.1:5000 — появится карта.
6. Настройте параметры (режим сетки/дорог, источник улиц, Advanced Optimization), выполните «🎲 Автораспределение».
7. Нажмите «💾 Сохранить и построить». Во время маршрутизации:
   - лог показывает стадии (чтение, распределение, построение, экспорт);
   - линии маршрутов рисуются на карте в реальном времени;
   - после завершения появляется кнопка «⬇️ Скачать KML» и слой с итоговыми маршрутами.

## Ключевые особенности

- **Живой прогресс:** сервер транслирует все этапы и геометрию маршрутов по мере построения (`route_step`).
- **Компактное автораспределение:** KMeans по клеткам или дорогам, продвинутая балансировка улиц с использованием обратного геокодинга Google/Yandex.
- **Гибкие настройки:** тумблеры режима (Grid / Road), источника названий улиц, Advanced Optimization, параметры сетки и траекторий.
- **Кэширование и ретраи:** геокодер сохраняет результаты в `cache/streets_cache.json` и повторяет запросы при сбоях.
- **Экспорт:** маршруты формируются в `data/routes_grid.kml`, дополнительно создаётся `data/roads_colored.kml` при построении.

## Описание переменных окружения (`.env`)

| Переменная | Назначение |
|------------|------------|
| `FLASK_HOST`, `FLASK_PORT` | адрес и порт сервера |
| `SECRET_KEY` | секрет Flask |
| `GOOGLE_MAPS_API_KEY` | ключ Directions + Geocoding |
| `YANDEX_GEOCODER_API_KEY` | ключ Yandex Geocoder |
| `GOOGLE_MAX_WAYPOINTS` | ограничение точек для Directions (23 по умолчанию) |
| `REQUEST_PAUSE` | пауза между запросами к API |
| `SAMPLE_EVERY_M` | шаг дискретизации линий при live-визуализации |
| `STREET_SOURCE` | источник названий улиц (google/yandex) |
| `ADVANCED_OPTIMIZATION` | включение расширенной балансировки |
| `TARGET_KM_PER_TRACTOR` | целевая длина маршрута на трактор |

## Папка `data/`

- `GEO.kml`, `RoadCity.kml` — входные файлы (добавьте сами).
- `grid.geojson` — автогенерируемая сетка клеток.
- `assignments.json` — ручные назначения клеток.
- `roads_assignment.json` — назначения дорожных сегментов.
- `routes_grid.kml` — финальный результат для загрузки.
- `roads_colored.kml` — дороги, окрашенные по трактору.
- `street_summary.csv` — отчёт по улицам (advanced режим).

## CLI-режим

Маршрутизатор можно запускать отдельно:
```bash
python route_builder_grid_v7_1.py \
  --geo data/GEO.kml \
  --roads data/RoadCity.kml \
  --roads-assignment data/roads_assignment.json \
  --output data/routes_grid.kml
```

CLI выводит прогресс и события `[ROUTE_STEP]`, `[ROUTE_DONE]`, которые сервер использует для live-визуализации.

## Диагностика

- Если нет `GEO.kml` или `RoadCity.kml` — в UI появится баннер и кнопка построения будет заблокирована.
- При отсутствии `GOOGLE_MAPS_API_KEY` маршруты соединяются прямыми сегментами (лог содержит предупреждение).
- Все ошибки Flask и фонового процесса возвращаются как JSON и появляются в логе интерфейса.

Готово! Проект можно запускать «из коробки», визуализировать прогресс и сразу выгружать маршруты.
